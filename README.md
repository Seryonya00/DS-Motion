# DS Motion: портфолио с админ-панелью

Сайт на Next.js 14. Работы берутся прямо из папки Google Drive:
папка = категория, вложенная папка = подкатегория, файлы (фото и видео) = работы.
Загрузил работу в Drive, нажал «Синхронизировать» в админке, и она на сайте.

## Что умеет админка (`/admin`)

- скрывать и показывать категории, подкатегории и отдельные работы
- переименовывать категории и работы, добавлять описание категории
- менять порядок стрелками
- выбирать обложку категории и «избранные» работы для веера на главной
- редактировать тексты: заголовок, «Обо мне», услуги, программы, цифры, ссылки
- кнопка «Синхронизировать с Drive»

Новая категория создаётся как новая папка в Google Drive.
Сайт сам перечитывает Drive каждые 5 минут, кнопка нужна, чтобы увидеть изменения сразу.

## Запуск

### 1. Google API key (чтобы читать папку Drive)

1. https://console.cloud.google.com, создай проект.
2. APIs & Services, Library, включи **Google Drive API**.
3. Credentials, Create credentials, **API key**. Скопируй ключ.
4. Папка с работами в Drive должна быть открыта: «Все, у кого есть ссылка, Просмотр».

### 2. Хранилище настроек (бесплатно)

В проекте на Vercel: Storage, Marketplace, **Upstash Redis**, Create.
Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами.

### 3. Деплой на Vercel

1. https://vercel.com, Add New, Project, выбери репозиторий `DS-Motion`.
2. Settings, Environment Variables:

| Переменная | Значение |
|---|---|
| `GOOGLE_API_KEY` | ключ из шага 1 |
| `ADMIN_PASSWORD` | пароль для админки |
| `SESSION_SECRET` | любая длинная случайная строка |
| `DRIVE_FOLDER_ID` | не обязательно, по умолчанию уже стоит папка «Работы» |

3. Deploy. Админка: `https://твой-сайт/admin`.

### Локально

```
npm install
npm run dev
```
Переменные положи в `.env.local`. Без Upstash настройки пишутся в `.data/settings.json`.

## Структура

- `app/page.js`: главная
- `app/c/[id]/page.js`: страница категории
- `app/admin`: админ-панель
- `app/api/admin/[action]/route.js`: login, logout, settings, sync
- `lib/server.js`: Drive, хранилище, авторизация
- `lib/shared.js`: общие функции и тексты по умолчанию
- `components/`: интерфейс
